## Locked decisions (Phase 0 audits + user rulings)

- **KEY = EnemyType 6 everywhere** (5 = LAMP in ROM table — editor enum skips 5).
  JSON enemy types valid = 0-4, 6.
- **Emission = hot-record stream b7 masks** (no new tables, no layout shift;
  legacy masks $00/$08/$10/$20/$40 never set b7 → generated byte-identical):
  - `$80` phase cell: `[mask, 2c, row, 2, 1]` one record per cell (left half;
    runtime mirrors), cycle b0 = on/off (64f).
  - `$81` vcrunch bbox: `[mask, x, y, w, h]`.
  - `$82` hcrunch band prefix: `[mask, 0, band, 2*(n+1), 1]`.
  - Count byte includes feature records.
- **Door = MetaB b7** (`ball_col+1 | $80`), computed by `model_door_flag(model)`.
  Staging must mask b7 in Phase 2 (staged RAM is wall-only).
- **KeyHeld = `LevelStartRoom $A7` b7** (write kernel, read needs `and #$7F`).
- **Door open = `EnemyDeadMask b3`**; phase/vcrunch/hcrunch dead bits b5/b6/b7
  of `$BA`, zeroed at EnterRoom.
- **Crunch state = clock-derived only** (no state bytes; ZP 100% full).
  hcrunch 4.27s cycle (user-chosen), vcrunch 16f/step, phase 64f blink.
- **Key art = OBJ_NONE offset-0 slot reuse** (ObjBase=0 → $FF sentinel);
  key persists across rooms, death keeps state.
- **CTLPF 4clk = per-frame write** (kernel) driven by a per-room ROM table
  (no ZP byte).
- New kernel code bodies go to **bank2 tramp pads** — bank0 pre-pad headroom
  is 1B (limit $FC68).
- **Interpretation rulings (user, 2026-10-12):**
  1. Phase/vcrunch on the hot middle band = **hard error** (convert raises;
     editor warns on mouse release).
  2. Hcrunch + hot band = **allowed** (C cells keep their char — they are
     crunch, not hot; the band's other cells stay hot).
  3. Editor live feature checks fire **on mouse RELEASE only**, never
     mid-drag (drag legitimately passes through invalid layouts).
