## Locked decisions (Phase 0 audits + user rulings)

- **KEY = EnemyType 6 everywhere** (5 = LAMP in ROM table — editor enum skips 5).
  JSON enemy types valid = 0-4, 6.
- **Emission = hot-record stream b7 masks** (no new tables, no layout shift;
  legacy masks $00/$08/$10/$20/$40 never set b7 → generated byte-identical):
  - `$80` phase cell: `[mask, 2c, row, 2, 1]` one record per cell (left half;
    runtime mirrors), cycle b0 = on/off (64f).
  - `$81` vcrunch bbox: `[mask, x, y, w, h]`.
  - `$82` hcrunch band prefix: `[mask, 0, band, 2*(n+1), 1]`.
  - Count byte includes feature records.
- **Door = MetaB b7** (`ball_col+1 | $80`), computed by `model_door_flag(model)`.
  Staging must mask b7 in Phase 2 (staged RAM is wall-only).
- **KeyHeld = `LevelStartRoom $A7` b7** (write kernel, read needs `and #$7F`).
- **Door open = `EnemyDeadMask b3`**; `$BA` feature bits (final, 2026-10-13):
  b5 = phase armed (staged by PhaseBlink each VBL), **b6 = phase removed
  (latch set at the crush kill; punch forced open until EnterRoom)**,
  b7 = free for vcrunch/hcrunch — zeroed at EnterRoom.
- **Crunch state = clock-derived only** (no state bytes; ZP 100% full).
  hcrunch 4.27s cycle (user-chosen), vcrunch 16f/step, phase 90f blink
  (mod-90 staging → 45 on / 45 off, +40%).
- **Key art = OBJ_NONE offset-0 slot reuse** (ObjBase=0 → $FF sentinel);
  key persists across rooms, death keeps state.
- **CTLPF 4clk = per-frame write** (kernel) driven by a per-room ROM table
  (no ZP byte).
- New kernel code bodies go to **bank2 tramp pads** — bank0 pre-pad headroom
  is 1B (limit $FC68).
- **Interpretation rulings (user, 2026-10-12):**
  1. Phase/vcrunch on the hot middle band = **hard error** (convert raises;
     editor warns on mouse release).
  2. Hcrunch + hot band = **allowed** (C cells keep their char — they are
     crunch, not hot; the band's other cells stay hot).
  3. Editor live feature checks fire **on mouse RELEASE only**, never
     mid-drag (drag legitimately passes through invalid layouts).

## Placement rules R1–R5 (user-approved 2026-10-14)

list (convert raises, `verify_build` gates, editor guards on mouse

- **R1** door / phase / vcrunch / hcrunch live ONLY on **model row 1**
  (middle band, display tiles 4-7). Rows 0/2 are entry/exit corridors.

  hcrunch (convert raises on any mix).
- **R3** room-shape caps: vcrunch/hcrunch rooms = **no objects**; door
  rooms = **≤1 non-key enemy, no lamp/miner/raft/magma**; phase rooms
  unrestricted.

  door/phase only (user rule amended 2026-10-14: **vcrunch/hcrunch ARE
  allowed on hot** — both crunch walls respect the hot flag: hot ON =
  touching any part of the drawn block kills; convert flags it in
  MetaB b6 and the kill gates use touch semantics when b6 is set).
- **R5** raft + tentacle only on the **bottom band** (model row 2) over
  an AIR cell, and only in rooms with `bottom_band: true`.

## Phase 7 — async walls move MODEL → ROOM (2026-10-17, user ruling)

**Why:** one model SHAPE must be reusable by rooms with different async (a door
here, a phase wall there), and it makes the editor simpler — the room owns its
own behaviour layer instead of the model owning a shared one.

**Scope:** the asym strips (ball/M1/door, was `ModelData.asym_patches`) AND the
phase/vcrunch/hcrunch feature cells (were `P`/`V`/`C` grid tiles).
`mid_band_type` (hot) and raft stay model properties.

**Encoding (relocated, not re-invented):** `room.asym_patches` =
`[[row, col, tile, side?], ...]`; `room.feature_cells` = `[[row, col, tile], ...]`.
A model's P/V/C tiles become SOLID_WALL — the same PF byte, since
`tile_to_char()` already rendered them solid.

**Implemented:**
- `tools/migrate_async_to_rooms.py` (idempotent) migrated `src/rooms`,
  `src/tests/rooms`, `src/tests/qa/rooms`.
- `convert_level`: `rows_from_json` overlays the room's feature cells;
  `resolve_asym_patches(model, room, rows)`; `room_door_flag` /
  `room_m1_door_flag` / `async_kinds`; a room with async gets its own
  `(PF + meta + stream [+ Right*])` block emitted into the LEVEL TABLE FILE so
  `emit_spills` owns the placement; a model shared only by async rooms emits no
  `M<id>` block. `emit_spills`' `spill_F767` start corrected to `$F700`.
- `verify_build`: model blocks are static (`MetaA $00`, `MetaB $00|$40 hot`);
  each async room's block is cross-checked through the same envelope gate.
- Editor: `RoomData` carries the async (optional keys, legacy-safe load),
  `DataSerializer::MigrateAsyncToRooms` migrates a legacy project once at
  startup, the selftest round-trips a level + the migration.
- **Remaining editor step:** the brush UI. The async brushes currently refuse
  (one-shot dialog) instead of writing the retired model form; the next step
  retargets them (and the validation/render helpers: `ModelSpecialBits`,
  `FindPatch`, `BuildRightRows`, `RightRectsOk`, the door/feature rendering) to
  the active ROOM and moves them to the level tab.

**Evidence the move is semantics-preserving:** a room-by-room dump
(`LEVELn_RoomDataTable` → PF triples + MetaA/B + rect/hot stream) is
byte-identical for all 16 live rooms before vs after (only label placement, and
hence the ROM md5, moved). Build green, battery 38/38, QA sweep end to end.
