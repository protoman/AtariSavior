`M<id>`/`L<n>R<r>` blocks. A walker executes `lda (FetchPtr),Y` in its own
bank, so walker and block must be co-resident. There is no ordering of
per-walker moves that keeps the build green: moving the data first breaks the
bank3 walkers, moving a walker first breaks it on the data. The only green
decomposition is duplicate-then-delete (§5).

## 5. Ordered chunks (each independently green)

### C1 — bank2 window prep + placement map (0 ROM, 0 behavior) — **do first**
- Delete the three empty spill slots (`$F864`, `$F970`, `$F9D9`) from

  `_SPILL_SLOTS` / `_SPILL_ORG` / `check_level_window` / `bank2_data_slots`
