# Prototypes of the HERO-style cave kernel (history)

`v1/` abs,X/Y counters; `v2/` shared Y + biased pointers; `v3/` one band code run 4x with the
water line. `v3/run_proto.py` still runs (`python3 tools/proto/v3/run_proto.py`): a standalone
4K ROM measured with tools/tia_render.py (tagged art).

The production kernel is generated by `tools/cave_kernel_gen.py` (bank6.asm, see
docs/agents/cave_kernel.md) and verified on the real ROM by `tools/test_cave_kernel.py`.
